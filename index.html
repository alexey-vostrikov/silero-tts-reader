apt-репозиторий

Пакеты последних пяти выпусков. В репозитории лежат все версии сразу, поэтому можно поставить конкретную.

Подключить

sudo install -d -m 0755 /usr/share/keyrings
curl -fsSL https://alexey-vostrikov.github.io/silero-tts-reader/apt-key.gpg \
  | sudo tee /usr/share/keyrings/apt-key.gpg > /dev/null
echo "deb [signed-by=/usr/share/keyrings/apt-key.gpg] \
https://alexey-vostrikov.github.io/silero-tts-reader/repo stable main" \
  | sudo tee /etc/apt/sources.list.d/apt-key.list
sudo apt update

Поставить

sudo apt install silero-tts-reader

Поставить конкретную версию

apt list -a silero-tts-reader
sudo apt install silero-tts-reader=<версия>
